# Reference documents

- `encoding.md` — the Protocol Buffers wire-format specification ("Encoding",
  from the protobuf.dev programming guides), vendored verbatim from
  https://github.com/protocolbuffers/protocolbuffers.github.io/blob/main/content/programming-guides/encoding.md
  (rendered at https://protobuf.dev/programming-guides/encoding/). It is the
  design authority for this task: every behavioral rule in `protobuf.md` and
  in the `protobuf_spec.mbt` docstrings is traceable to it.
- `protobuf.md` — this repository's codec-oriented summary of the wire format
  and the conventions of the MoonBit API and test suite.
